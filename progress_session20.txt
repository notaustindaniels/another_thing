### Implementation notes

- **_parse_cube_lut(path)**: Parses .cube LUT files per the standard spec
  (R-fastest, B-slowest iteration order). Returns (N, N, N, 3) float32 array
  with axis order (B, G, R). Skips # comments, TITLE, DOMAIN_MIN/MAX lines.
  Raises ValueError if LUT_3D_SIZE is absent or entry count mismatches.

- **_apply_cube_lut(frame, lut)**: Vectorized trilinear interpolation — zero
  Python loops. Computes float indices, floor/ceil per axis, gathers 8
  cube corners from the lut array, interpolates R then G then B. Alpha
  channel is always preserved unchanged.

- **_apply_color_grade**: Replaced the stub with real logic: parse_cube_lut +
  apply_cube_lut. Warnings on missing file or parse failure (graceful).

- **_compute_fisheye_map(H, W, k1, k2)**: Computes backward-warp pixel
  map once, stores in module-level _FISHEYE_MAP_CACHE dict keyed by
  (H, W, k1, k2). Returns same numpy arrays on repeated calls (identity
  check passes). _apply_fisheye() accepts optional map_x/map_y to skip
  cache lookup in the hot path.

- **render_scene Step 0d/0e**: Precomputes fisheye map and LUT before the
  frame loop. Both passed as kwargs to _apply_global_post() for each frame,
  eliminating per-frame recompute cost.
